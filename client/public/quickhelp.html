Quick help

General controls

Left click
Select element or place new element in draw mode
Ctrl + Drag
Pan the canvas
Mouse wheel
Zoom in or out
Esc
Switch back to cursor mode

Editing

Click
Select element
Drag
Move selected element
Delete / Backspace
Delete selected element

Rotation

R
Rotate selected element
R (Draw mode)
Rotate preview element

Undo / Redo

Ctrl + Z
Undo last action
Ctrl + Y
Redo last undone action
Ctrl + Shift + Z
Redo with alternative shortcut

Modes

Cursor mode
Select and move elements
Draw mode
Place new elements on the grid
Tip: Use zoom and pan for precise placement. Undo/Redo helps experimenting safely.
